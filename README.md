# Databricks learning workspace

This repository is your Databricks study space. You already know Apache Spark, so tutoring and notes will build from that foundation and emphasize what Databricks adds, changes, or operationalizes.

## Study materials

- [Learning workspace](learning/README.md): how tutoring and note-taking are organized.
- [Books](learning/books/README.md): book list and per-book notes.
- [Combined notes](learning/combined/combined-notes.md): concepts synthesized across books.
- [Revision notes](learning/revision/revision-notes.md): concise prompts and reminders for review.

The first book is *Data Engineering with Databricks Cookbook* by Pulkit Chadha. Book-specific notes will be added as you share chapters, sections, reading notes, questions, or exercises; no chapter contents have been assumed in advance.
